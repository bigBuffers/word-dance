## 1 改了什么

| 面向 | 变化 |
|---|---|
| 精细图卡（记忆图卡） | 图直接画进页面，画里的单词按「单词之舞」跳一次：字母按音节入场、重读一拍、再做词义动作（需要道具、分身或变色的动作不做）。画面不动。点一下重播。已上线的精细图卡都生效 |
| 登录页的三个例子 | up 沿用已有的精细图卡；jump 用 11-13 画法试验里评分最高的那种画法画好、一直没用上的一张；cold 当天新画。访客演示接口如实说明图的种类，图片地址带 `?v=<图片 id>`（公开缓存一天，换图后不能再拿到旧图） |
| 设置 | 「单词之舞」关 / 系统减弱动态 → 不动；「只拼读」→ 不做词义动作；「图片上显示单词」关 → 和以前一样显示不带单词的画面 |
| 不变 | 词组等没有舞谱的词、照片、简笔画；跳动图卡照旧 |

实现：`DancingPicture` 认 `#word-art` 里的 `wa-<序号>-<字母>` 路径（同一序号的几条路径——如 j 的竖和点——一起动），用 `word/dances.ts` 的舞谱，1em = 画里单词的高度；内联的 SVG 每个实例给所有 id 加前缀（`scopeIds`），多张图同页不会串用渐变和滤镜。契约：`docs/API.md` §9.1、接口 77；`docs/FRONTEND.md` §4。
