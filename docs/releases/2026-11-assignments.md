## 1 是什么

| 面向 | 内容 |
|---|---|
| 谁能布置 | 管理员可以给任何学习账号布置；家长可以给自己名下的孩子布置；其他人没有入口 |
| 入口 | 设置 → 账号 → 「布置词汇」（`/assign`） |
| 怎么布置 | 选学生，输入单词（每行一个或逗号隔开，一次最多 50 个，词组照常写；也可以在「从词库里找」里搜到后点一下加入），选「今天就学」或「往后排」，可以起个名字。「预览」只看结果不写入，「布置」才生效 |
| 每个词会怎样 | 新词：进学生的生词库并排进词汇；学生已经在学：当天加练一次，不改它的复习间隔；学生已掌握 / 已认识：不布置，状态不动；词库里没有的拼写：先走查词校验，通过后再排 |
| 今天就学 | 学生今天的词汇已经生成时立刻追加进去；还没生成时在生成那一刻全部放进去，不受每天新词数限制，当天不再自动补别的新词 |
| 往后排 | 每天占用学生的新词额度，按顺序排完为止；今天的词汇已经生成时从明天开始 |
| 学生看到的 | 今日页多一行「老师布置 已完成 x/y」和词表；学习时这些词排在最前；可以跳过，不能删除 |
| 磨耳朵 | 布置的词排在播放列表最前；当天既有布置的词又有别的词时，多一个「全部 / 老师布置」的选择 |
| 进度 | 布置的人在同一页「我布置的」里看每个词表：共几个、已排几个、学完几个；点开看每个词排在哪天、评了什么、跳过几次；还没排的词可以撤回（撤回后仍是学生生词库里的普通新词） |

实现：迁移 0022 新增 `assignments`、`assignment_words` 两张表（只增不改，重启即生效）；`push_items` 没有改——布置的词就是普通的 new / extra / review 卡片，由 `assignment_words.push_item_id` 指过去。契约：`docs/API.md` 接口 124–129、§9 `Batch.assigned_item_ids`、`ListenItem.assigned`；`docs/FRONTEND.md` §4、§8。

这一版没有做：老师—班级—多个学生的关系；布置后的通知；单词以外的作业。
