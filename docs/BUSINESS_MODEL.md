# 单词之舞 盈利模式分析与设计（v0.2，待确认）

> 2026-11-11，为业主的问题「这款软件是否能实现盈利模式」而写。方法：同日五路联网调研、约 140 条带来源的事实（编号 R1-01 … R5-26，原文与来源收在 [`docs/analysis/2026-11-11-business-model/`](analysis/2026-11-11-business-model/) 的五个文件里，每个文件末尾列出未能从一手来源核实的条目，共 53 条），再结合本项目线上账本与部署文档的真实成本数字；初稿经三路对抗评审（证据一致性、合规怀疑、商业与产品怀疑，共 45 条意见）修订为本版。本文只做分析与设计，不改代码；第 6 节的改动清单等您确认后再排进切片。
> 一句话：**能做成「副业自给、略有盈余」的产品，做不成能养人的生意；而且在收第一分钱之前，有三道门要先过——两项与收费无关的授权问题（macOS 系统语音、智谱免费模型）、一份「学习工具还是校外培训」的书面法律意见、以及个人主体不能有偿提供信息服务的事实。**

## 0 一页结论

1. **能不能赚钱**：三档情景（第 5.5 节，已扣渠道费与税、含免费用户的变动成本）——口碑圈（300 月活）**亏** ¥3–5 千/年，因为收费本身要先花主体、备案、律师的钱；本地小爆款（5,000 月活 × 6 % 付费 × 净 ARPU ≈ ¥95）净约 **¥1–1.5 万/年**；小众头部（5 万月活 × 7 %）净约 **¥5–15 万/年**，但要公司主体、多年口碑和运气，而且核心用户群（小学生）每年缩 4 % 左右（R5-21～24）。付费率参照：多邻国 9 %（付费 / 月活，R5-03，十余年打磨的上限）、流利说 0.4 %（付费 / 累计注册，R5-04，口径不同，只作量级）、Apple 示例 3 %（下载后 60 天转化，R5-25）；工具类订阅 ¥18–25/月、¥98–168/年，面向家长的 K-12 产品 ¥168–268/年（R1 摘要 2–3）。
2. **成本侧的真相是一个设计前提，不是现状**：今天线上两位用户、按 Claude 牌价，学习者侧每人每月约 ¥12（夜间整理几乎每个学习日触发一次 ≈ ¥1.9，加上遇到尚无内容的词的即时生成）；而 6 % 付费 × ¥95/年 的收入折到每个月活只有 **¥0.5/月**。所以免费层的变动成本必须压到 **≤ ¥0.2/月活/月**，模型才成立：夜间整理与自添词全部走国产付费模型（百炼 qwen3.7-flash，¥0.2/¥0.8 每百万 token）、免费层自添词限额、自添词不即时生成而进运营者夜间批次。做到这些后，每月活变动成本约 ¥0.1–0.3（第 1 节）。全库预生成做完后，运营者侧的内容成本归零。
3. **收费前的三道门**：
   - **培训还是工具**：英语属学科类（R2-04）；一旦被定性为校外培训，个人没有任何合规路径（非营利法人、办学许可证、政府指导价，R2-01/02/07），对自然人有偿开展者还有退费与 5–10 万元罚款（R2-05 第十七、十八条）。无真人、无课表的自学工具在文义上更像「教育 App」，但**没有官方书面结论、没有先例**（R2 未核实 #1）。**先花 ¥2–5 千请教育监管方向的律师出具书面意见**，再谈收费。
   - **主体**：有偿信息服务 = 经营性 ICP，许可证只发公司（R2-13、R3-10）；个体工商户能开微信 / 支付宝商户号，但以个体户身份有偿提供信息服务是否被认可，各地通信管理局尺度不一（R3-10，置信低）。教育 App 提供者备案没有「个人」选项（R2-10、R3-27），而且这项义务在以学生 / 家长为主要用户的 App 上架时就产生（R2-09），不是以后再说的升级项。
   - **未成年人**：<8 岁付款无效、8–18 岁未经监护人同意可被要求返还（R2-17/18）——购买只能发生在家长账户，并在购买时做成年声明（账号类型不是年龄证明，R2-09 要求「后台实名、前台自愿」）。
4. **两项现在就该排期、与收费无关的授权阻断**（R4-01～03、R4-21）：
   - macOS 系统语音（Ava / Serena Premium）的软件许可只允许个人、非商业使用，并明文禁止录制、发布、再分发（含非营利与公开分享）。现在服务端用 `say` 合成并下发的 6,838 条片段（两种口音 × 3,419 条，R4-03）在公开服务里就已越线。替换为阿里云 CosyVoice / 通义 TTS / 火山豆包（0.8–3 元 / 万字符，R4-04～08）：按本库 9,618 词 × 两种口音连例句，一次性约 ¥220–980，可忽略。
   - 智谱免费模型 GLM-4.7-Flash 的用户协议只允许「非商业的、个人研究学习」用途（R4-21）；运营侧内容生成走 Claude Code 订阅与 Consumer Terms「禁止非 API 的自动化访问」相抵（R4-20）。付费版：学习者侧换百炼 / 智谱付费模型，运营侧用 API key（Commercial Terms 下输出归客户，R4-17）。
5. **推荐模式**（第 5 节）：**全部学习内容永远免费、不限量**（词库、例句、图卡、三种舞、发音），付费的是**家长看得见的东西**——每周学习报告与「今天没学」提醒（主卖点）、多个孩子、自添词配额与自添词的发音 / 图卡——两种付法并列：**年付 ¥128** 或 **一次性永久 ¥198**（墨墨 ¥163 / 欧路 ¥168 的区间，R1-01/19），再加月付 ¥15 / 季付 ¥38。书面意见到手前只售月 / 季。iOS 走 Apple IAP（以个体户名义注册的开发者账号，Small Business Program 大陆佣金 12 %，R3-01/03/04）；网页 / APK 走个体户商户号的**一次性购买**（个体户一般拿不到自动续费资格，待核实）；小程序支付不在第一阶段。
6. **分三阶段**（第 5.4 节）：阶段 0（现在）免费 + 口碑，先清掉授权阻断、把免费层成本做到位；阶段 1（律师意见 → 个体户 → 备案 → Apple IAP → 网页一次性购买，年固定 ¥4–7 千）开始收家庭版；阶段 2（一人有限公司）才做教育 App 备案、等保二级、安卓商店与学校渠道。每一阶段都有退出条件。

## 4 可选模式评估

评分 1–5（5 最好）：合规难度（高分 = 容易）、收入潜力、实现成本（高分 = 便宜）、与产品一致性。

| 模式 | 合规 | 收入 | 实现 | 一致性 | 评语 |
|---|---|---|---|---|---|
| A 家庭版订阅（家长付费、全家共用） | 3 | 4 | 3 | 5 | 与家长 / 子账号模型天然契合；背着自动续费与预付规则（R2-20～23），前提（培训定性）待咨询 |
| B 一次性买断（墨墨式 / 欧路式永久） | 5 | 3 | 4 | 4 | 无续费合规负担、对家长心理友好；R1 里两个小团队盈利样本（墨墨、欧路）都是买断；年收入天花板低 |
| C 阶段包（中考包 / 高考包） | 3 | 3 | 4 | 3 | 「包」字容易被读成课程 / 培训；不单独做 |
| D 学校 / 班级 B2B | 2 | 3 | 2 | 3 | 进校园 App 不得向学生 / 家长收费、须备案 + 双审核（R5-18/19）；只剩「卖给学校」（公司 + 招投标）或「校内免费 + 家庭付费」 |
| E 赞赏 / 捐赠 | 5 | 1 | 5 | 3 | 个人阶段唯一无需执照的渠道；收入可忽略，可做「支持开发者」入口 |
| F 内容库授权 | 3 | 2 | 3 | 2 | 内容不受版权保护（R4-25～27），议价力弱；需公司 |
| G 广告 | 1 | 2 | 3 | 1 | 儿童产品 + 广告法 + 双减叙事，否 |
| H 硬件捆绑 | 2 | 2 | 1 | 2 | 家长预算确实流向硬件（R5-10/12），一个人做不了供应链 |

**推荐：A 与 B 并列为主（「年付或永久买断二选一」，由前 100 位付费家庭的选择决定侧重）、E 作个人阶段的过渡、D 留阶段 2；不做 C 的单独包装与 G / H。** 主卖点是「家长看得见」（周报与提醒），不是多孩——多数目标家庭只有一个学龄孩子，R5 的结论也把家长可见进度而非多孩列为转化驱动。

## 5 推荐设计：全部学习免费 + 家长侧付费

### 5.1 免费层（永远免费，且有成本硬约束）

**内容全部免费、不限量**：全部学段的词库、例句、图卡、拼写舞 / 重音舞 / 语义舞、服务器发音（换云 TTS 后）、每日学习、筛词、生词本、导出、每日提醒；手机号 / 邮箱 / 密码 / 微信登录；孩子账号的时间管理、设备管理（登录码、退出所有设备）、消费管理（义务，R2-15 第四十三条）。升学换学段免费。不做广告。孩子的学习本身不被付费墙切断——这是产品立场，也避开「向未成年人劝诱购买」（R2-24）。

**免费层的成本约束（第 1.2 节的前提，必须实现）**：自添词每日 ≤ 5 个且不即时生成（提交后进运营者夜间批次，次日可见）；夜间整理走百炼；自添词的服务器发音与图卡仅家庭版；每月活变动成本目标 ≤ ¥0.2。

### 5.2 家庭版（付费，只能由家长账户购买）

| 权益 | 说明 | 为什么值钱 |
|---|---|---|
| **家长周报与提醒**（主卖点） | 每周学习摘要（学了多少、连续天数、薄弱词）推到微信 / Bark / 邮件；孩子当天没学的提醒 | 家长看得见才肯付；家庭英语预算存在但流向「看得见的东西」（R5-10/12） |
| 多个孩子 | 子账号从 1 个放开到 10 个 | 二孩家庭的直接需求；国内词汇 App 几乎没有 |
| 自添词配额 | 每日 50 个、可申请即时生成（仍在运营者批次内优先处理）、自添词的服务器发音与图卡 | 高中 / 四六级学习者的真实需求，也是最贵的用量 |
| 优先支持 | 词条纠错 / 建议优先处理 | 低成本 |

**定价**（与 R1 锚点对齐、落在 Apple 价位阶梯上）：月付 ¥15、季付 ¥38、年付 ¥128、一次性「家庭永久」¥198。**律师书面意见到手前只售月 / 季**；年付与永久随意见上线，永久卡的法律性质（软件许可而非预付服务）由律师确认。邀请的朋友家庭首年 ¥68 以独立 SKU「邀请价」展示，不划线显示 ¥128，直到 ¥128 有真实成交记录；促销期限明示（R2-22）。

**付费流程合规要点**：购买入口只在家长账户（`account_kind='guardian'`）出现，孩子账号与切换中的会话不显示任何价格；购买时勾选「本人已年满 18 周岁且为被购买子账号的监护人」并记录时间与 IP，永久卡等大额购买可要求实名核验（阿里云号码认证已有）；购买页明码标价、显示续费 / 到期规则；网页渠道到期前 7 日邮件 / 站内 / Bark 提醒续购并可随时关闭提醒；网页渠道 7 天无理由退款，IAP 按 Apple 流程并在购买页说明；消费记录可在设置页查看、导出并申请电子发票；若被定性为培训而停止收费，按剩余期限退还已收款（永久卡全额）。

### 5.3 收款渠道

| 端 | 渠道 | 费率 | 主体与说明 |
|---|---|---|---|
| iOS 壳 | Apple IAP（自动续费订阅 + 非消耗型「家庭永久」） | 25 %，Small Business Program 12 %（2026-03-15 起，R3-03/04） | **个体工商户名义**的 Apple Developer 账号（R3-01），收入归个体户按经营所得申报；工信部 App 备案在先（R3-07/08）；IAP 同样面对经营性 ICP 问题（须咨询） |
| 网页 / Android APK / 鸿蒙 | 微信支付 + 支付宝 商户号，**一次性购买 1 / 3 / 12 个月 + 永久** | 0.6 % | 个体工商户营业执照（R3-17/20）；个体户一般无委托代扣资格（待核实）→ 不自动续费；通信管理局答复为「须许可证」→ 停网页收费、转公司或只保留 iOS |
| 微信小程序 | 虚拟支付 | Android 1 %，iOS 12 % | **阶段 2 候选**：需核实官方口径与「教育」类目（R3-21/22），且需一个独立的小程序客户端（现有的只是登录桥） |
| 个人阶段过渡 | 微信赞赏码 / 爱发电 | — | 不能作为订阅对价（R3-19/30） |

服务端需要一个统一的「权益」层：订单表（渠道、外部订单号、商品、金额、币种、状态、到期日）、家庭版状态（家长账户上的有效期 / 永久标记）、权益门（子账号数、自添词配额、周报开关），以及两个支付适配器（Apple App Store Server API 通知校验、微信支付 v3）。
