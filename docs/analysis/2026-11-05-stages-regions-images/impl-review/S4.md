## 4 Findings（按严重度）

**F1 · minor · `frontend/src/components/word/SpeakButton.test.tsx`（WordHeader 用例）/ `WordRow.test.tsx` / `StudyCard.test.tsx`** — PLAN §6 S4 明确要求的 `WordHeader.hasMeta → showStages` 改动没有任何测试覆盖：把它改回旧条件后 312 个测试全绿（M7）。后果：一个 `stages=[]` 且无音标的课标外词（P6 的 238 个词里不少没有 ECDICT 音标；自定义/待校验词也常无音标）在学习卡与详情页上会整行 meta 消失、看不到「课标外」芯片，而 CI 不会发现。同样，`onlyStages` 的三段管线（`WordRow → StageChips`、`StudyCard → WordHeader → StageChips`、三个页面传 `settings?.stages`）也只在 `VocabPage.test` 里 mock 了 `settings.stages` 却没断言芯片（`getVocab` 返回空列表）。建议：在 `SpeakButton.test.tsx` 的 `WordHeader` describe 里加一例 `{ stages: [], stage_min: null, phonetic: null }` → 渲染 `课标外`；在 `WordRow.test`/`StudyCard.test` 各加一例 `onlyStages={['xs']}` → 只剩最低阶段芯片。

**F2 · minor · 实现者报告的「偏离 / 请求」（`ScreenRunPage.tsx` / `ScreenCard.tsx`）** — 报告称「ScreenCard.tsx 不在任何切片清单里，所以 `/screen/:stage` 上的 `only` 收窄尚未生效（见 requests）」。实际 `ScreenCard.tsx:91` 是 `showStages={false}`，筛词卡按 FRONTEND §5.4 只显示词头 + 音标 + 🔊，根本没有阶段芯片可收窄；PLAN §6 S4 的这一条是写错了组件名的空操作，不存在功能缺口，也不需要 S7 或任何人改 `ScreenCard`。建议：撤回该请求，在 S7 交接里注明「ScreenRunPage 无需改动」，以免集成者误加 `onlyStages`/打开 `showStages`。
