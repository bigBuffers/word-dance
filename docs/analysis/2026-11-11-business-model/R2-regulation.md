# R2 — 监管边界：K-12 学习 App 在大陆收费的法规约束

核查日期：2026-11-11。研究视角：一名个人开发者（无公司）做的 K-12 英语词汇训练器（预生成 + 人工整理的内容，无直播、无真人授课，含家长 / 儿童账户）能否、以及在什么条件下向用户收费。所有条号仅在官方页面原文中读到时才标注；未读到原文的一律标「未核实」。

## 摘要（对一人 K-12 词汇 App 的含义）

1. **「英语」是学科类**（R2-04）。只要监管把产品定性为「校外培训」，就落入双减最严的一档：义务教育阶段学科类机构须登记为**非营利性法人**、不得资本化、收费执行**政府指导价**、不得占用节假日寒暑假、线上须**省级审批 + 办学许可证**（R2-01/02/07）。个人没有任何一条路能取得这些资质。
2. **「培训」与「学习工具」之间没有官方的成文界线**。可查到的定义都是面向「有组织或系统性的教育培训活动」（R2-08 征求意见稿）、「擅自举办」要件含「2 名以上培训从业人员 + 组织机构分工」（R2-05）、隐形变异情形含「直播变录播」「证照不全的机构或个人以咨询等名义开展」（R2-06）。一个无教师、无课表、无真人服务、纯自学的词汇工具**在文义上更接近教育 App 而非培训机构**，但这只是推论，不是任何机关的书面结论（见未核实 #1）。「学科类培训 App」被教育部单列处理：未取得线上学科类培训许可的，备案一律撤销（R2-11）。因此产品叙事必须**彻底避开**「课程」「课时」「补习」「提分保证」「老师」这些培训信号。
3. **「个人」身份是收费的硬障碍，而且与教育监管无关**：有偿提供信息服务 = 经营性 ICP，需要许可证，而增值电信业务经营者「为依法设立的公司」（R2-13）；教育 App 提供者备案表的「单位性质」只有机关 / 事业 / 企业 / 社团 / 民非，无「个人」选项（R2-10）。结论：**要收费先要有一个公司主体**（至少一人有限公司；个体工商户是否能过教育 App 备案与经营性 ICP 两关，未核实，见 #2）。工信部 App 备案（R2-14）个人可办，但只解决「能上架」，不解决「能收费」。
4. **向未成年人收钱的民事风险是刚性的**：<8 岁的付款行为无效、8–18 岁未经监护人同意 / 追认且与年龄智力不相适应的支出可被要求返还（R2-17/18）。产品若由**家长账户付费、孩子账户只使用**，这条风险基本消失；这正好与现有 guardian/child 设计吻合。网络游戏的 50/200、100/400 元月限额只约束游戏企业（R2-19），但《未成年人网络保护条例》第四十四条用「等网络服务提供者」开放了外延（R2-15），做「消费管理」功能是低成本的防御。
5. **订阅合规是成熟的清单项**：自动续费须在接受服务前和续费日前显著提醒（实施条例第十条，R2-20），网络交易办法要求**前五日**提醒并提供随时取消（R2-21）；预付须书面合同、可退余额（R2-20）；页面明码标价、禁止虚假折价与「谎称政府指导价」（R2-22）。若被认定为培训机构，还叠加「一次性不得超过 3 个月 / 60 课时、不超过 5000 元」与银行托管（R2-23）——所以**不要做长周期（年付以上）预付包**，并把「月付 / 季付」作为上限是最安全的默认。
6. **生成式 AI 两部规章对「运营者触发、人工审核、静态展示」的预生成内容大概率不适用**（第二条「向公众提供生成…内容的服务」且「研发、应用…未向境内公众提供服务的不适用」，R2-25），但一旦**让用户点按钮生成**例句 / 舞步，就进入适用范围：防沉迷、标识（文本显式 + 元数据隐式，R2-26）、必要时安全评估 / 算法备案。教育部 2025 指南**禁止小学生独自使用开放式内容生成**（R2-27），这是进校园与面向小学生推广时的实际红线。
7. **广告**：教育培训广告不得作保证性承诺、不得利用机构 / 专业人士名义推荐（R2-24）；双减要求网络平台不刊登校外培训广告（R2-03）；面向 <14 岁的广告不得「劝诱其要求家长购买」（R2-24）。投放渠道上，走「学习工具 / 家长端」而非「培训课程」叙事既是合规也是营销现实。

**一句话**：合规路径 = 注册公司 → 经营性 ICP + 等保 + 工信 App 备案 + 教育 App 提供者备案 → 家长付费、孩子使用、月 / 季订阅、五日前续费提醒、明码标价 → 不碰「培训 / 课时 / 老师 / 提分」叙事、不开放用户触发生成。任何一环走不通（尤其是教育 App 备案是否接受非培训的学科工具）都应先问当地省级教育行政部门。

## 对产品决策的映射（由上表推出，不是新事实）

- **可以收的钱**：面向家长账户的订阅 / 会员（月、季），内容为词表、例句、发音、动作卡片等自学材料；不出现「课时」「老师」「班级」「保分」。
- **不能或不宜做的**：以培训机构身份运营（个人无资格，R2-01/07/10）；年付以上大额预付（R2-23 的 3 个月 / 5000 元若被类推）；孩子账户内直接付费 / 充值（R2-17/18）；面向 <14 岁的「让爸妈买」式引导（R2-24）；用户自由触发 LLM 生成（R2-25/26/27）。
- **启动前必须有的主体与备案**：公司 → 经营性 ICP 许可证（R2-13）→ 等级保护定级备案 → 工信部 App 备案（R2-14）→ 教育 App 提供者备案（R2-10）；儿童个人信息专门规则 + 监护人同意流程（R2-16）；未成年人模式与监护人的时间 / 消费管理（R2-15）。
- **订阅文案与流程**：页面明码标价（R2-22），自动续费在购买前与扣费前五日显著提醒、一键取消（R2-20/21），预付须有书面（电子）合同与退款条款（R2-20）。

## 未核实 / 待办

1. **「无真人、纯自学的学科词汇 App 是否属于校外培训」没有任何官方书面结论。** 现行定义（R2-05 第十七条要件、R2-08 征求意见稿第二条「有组织或系统性的教育培训活动」）更偏向「机构 + 人员」模型，但各地教育行政部门有裁量权，且 R2-11 明确存在「学科类培训 App」这一类别并要求培训许可。待办：以书面形式向目标注册地省级教育厅校外培训监管处 / 教育 App 备案窗口咨询，或请一位教育法律师出具意见后再定价。
2. **个体工商户能否通过教育 App 提供者备案与经营性 ICP 许可**：备案表「单位性质」无个体工商户选项但列了「等」（R2-10）；电信条例要求「公司」（R2-13）。未找到任何省级备案平台的公开说明。待办：在 app.eduyun.cn 与住所地通信管理局分别询问；默认按「需一人有限公司」规划。
3. **教育 App 备案对「含付费内容的学科学习工具」的实际审核口径**：教育部答复函只说「从…收费规范等方面从严审核」（R2-11），无公开标准；各省通过 / 驳回案例未查到。
4. **《校外培训管理条例》是否已正式公布**：2024-02 征求意见稿之后未检索到国务院令文本（搜索范围 gov.cn / moe.gov.cn，2026-11-11）。若已公布，R2-08 的定义与法律责任条款会直接取代 R2-05/06 的部门规章地位，需重查。
