# R4 — 付费版要卖的内容与媒体的授权状况（content licensing）

研究日期：2026-11-11 · 研究者：R4 lens（Claude 子任务） · 产品：单词之舞（word-dance），个人开发者，无公司主体

## 摘要（对一人维护的 K-12 单词 App 意味着什么）

1. **直接拦路虎只有一个：macOS 系统语音。** macOS Sequoia / Tahoe 26 的软件许可协议 §2.F 把 Ava (Premium)、Serena (Premium) 这类 "System Voices" 的使用限定为「个人、非商业」，并点名禁止「录制、发布、再分发……无论营利、非营利、公开分享还是商业场景」。现在服务端用 `say` 预生成 3419 条音频并通过 `GET /media/audio` 下发给 HarmonyOS / Android 用户，这已经越线；一旦收费，越线更明确。**上线付费前必须换掉**（R4-01 ~ R4-03）。
2. **替代 TTS 极便宜**：阿里云 CosyVoice 2 元/万字符、通义千问3-TTS-Flash 0.8 元/万字符、火山引擎豆包语音合成 2.0 按量 3 元/万字符（资源包 2.1~2.8 元）。整个高考 3500 词 + 例句一次性合成估算只要几十到两百元人民币，属于「一个下午就能迁移」的成本（R4-04 ~ R4-08）。
3. **ECDICT 是 MIT**，只需在 App「关于/开源许可」页保留版权声明和许可全文即可商用；但它的释义数据源头（cdict rpm、金山词霸时代的释义、网友贡献、柯林斯星级 / 牛津 3000 标签）上游权利不清，MIT 只能保证「作者 Linwei 不告你」，不能保证第三方不告（R4-09、R4-10）。
4. **词表本身在中国基本不受著作权保护**：北京知识产权法院（2020）京73民终1897号（新东方诉墨墨背单词，2021-02-18 二审）明确：按考试大纲选词、按字母 / 词频 / 词根词缀划分和排序，都不构成有独创性的汇编作品。所以用考纲 / 课标词表风险低；真正有风险的是随词表一起拿来的**中文释义文本**（mahavivo 仓库的 TOEFL/GRE 释义来自 2003 版金山词霸，COCA 释义是爬虫抓的）——词可以留，释义要用自己生成的（R4-11 ~ R4-14）。
5. **Wikimedia Commons 图片可商用**，CC BY / BY-SA 需要在 App 内可达的位置标注作者、许可名称、许可链接、是否修改；未修改的图片放进 App 属于「汇集」而不是「演绎」，不会触发 BY-SA 的传染条款（R4-15、R4-16）。
6. **LLM 文本可以卖，但要换合同主体**：Anthropic Commercial Terms（API key）把 Outputs 归客户所有；而 Consumer Terms（Claude.ai / Pro / Max，含 Claude Code 订阅）明确禁止「通过自动化 / 非人工方式访问服务（API key 除外）」。当前「运营侧工作走 Claude CLI」这一路在付费产品里应切到 API key。更关键的是**智谱的免费模型（GLM-4.7-Flash）按其用户协议「仅可以非商业的、个人研究学习的方式使用」**，付费功能才允许商用——面向学习者的 split 模式一旦收费就必须改用智谱付费模型或百炼付费模型（R4-17 ~ R4-22）。
7. **面向未成年人的合规义务是三方叠加的**：Anthropic 要求未成年人产品做年龄核验、内容过滤、监测与「正在与 AI 交互」的披露；智谱 / 百炼协议把「安全评估 + 算法备案」责任推给向公众提供服务的你；国内《生成式人工智能服务管理暂行办法》第十条（防沉迷）和《人工智能生成合成内容标识办法》（2025-09-01 起）要求对 AI 生成文本做显式 / 隐式标识。预生成 + 人工审核的离线内容是否算「向公众提供生成式服务」仍有解释空间，但「AI 生成」标注和未成年人防沉迷是逃不掉的（R4-18、R4-19、R4-21 ~ R4-24）。
8. **AI 生成的释义 / 例句大概率不是「作品」**：北京互联网法院 2023 年「AI 文生图第一案」和常熟法院 2025 年案给了保护，但前提都是逐件可举证的人工提示词迭代与修改；苏州中院 2025-04 判「仅输入简单提示词的生成物不是作品」。批量跑出来的几万条例句不满足前者，意味着**别人可以合法抄走你的内容库**，护城河只能靠服务、数据与反不正当竞争法，而不是版权（R4-25 ~ R4-27）。

**会直接阻断付费的事项**：R4-03（macOS 系统语音下发）；R4-21（智谱免费模型商用）。其余是「要做但不难」的合规动作。
