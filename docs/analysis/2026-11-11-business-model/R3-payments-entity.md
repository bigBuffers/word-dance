# R3 — 一人开发者在大陆合法收钱的路径与主体选择（支付 / 实体 / 备案）

研究日期：2026-11-11。方法：WebSearch + 对官方 / 一手页面的 WebFetch；凡未能从一手来源确认的，标「未核实」。本文只回答「怎么合法收钱、每条路允许什么、最便宜的组合是什么」，不评估需求与定价。

## 摘要（对一人做 K-12 单词 App 意味着什么）

1. **iOS 是对个人最友好的一条腿**：大陆个人可直接注册 Apple Developer Program（¥688/年），用个人名义做工信部 App 备案即可上大陆商店；加入 Small Business Program 后，大陆佣金自 2026-03-15 起为 **12 %**（标准 25 %），订阅从第一个月起即按低佣金结算。Apple 自 2025-07 起按《国务院令第 810 号》把个人开发者的身份证号、收入、交易数每季度报送税务总局——收入是透明的，但报税仍由个人自己负责。
2. **Android 商店这条腿对个人基本关闭**：小米「暂不接受个人开发者账号申请」且 2024-12 起连个体工商户也不收；vivo 不支持个人注册；OPPO 据二手资料同样不支持；应用宝要营业执照 + 软著 + 备案。唯一仍收个人的主流商店是华为，但个人开发者的应用内购买**只能走华为 IAP**，不得接微信 / 支付宝。现实选择是：**官网直接分发 APK + 微信 / 支付宝商户支付**，或用微信小程序做 Android 侧的收费入口。
3. **收款主体最低要到「个体工商户」**：微信支付普通商户与支付宝 APP / 手机网站支付都要求营业执照（企业或个体工商户）；无证的「小微商户」只开放给餐饮、零售等线下行业，只支持 JSAPI / Native / 付款码，不支持 H5 / APP 支付，且只能由服务商代进件——不适合软件订阅。个人收款码按央行 259 号文自 2022-03-01 起不得用于远程非面对面的经营性收款。
4. **一个新口子：2026-09 起微信向「个人主体」小程序开放虚拟支付**（类目需含「工具」+ 小程序认证 + 备案），月上限 ¥10 万，Android 侧技术服务费 1 %、iOS 侧为 Apple 12 %。这是目前唯一不需要任何执照就能合规收软件订阅费的渠道，但依赖二手资料核实（官方文档页未能抓取全文），且「教育」类目是否可叠加未核实。
5. **个体工商户成本极低**：登记免费、线上 3 天左右；增值税起征点月 10 万 / 季 30 万（财政部 税务总局公告 2026 年第 10 号，至 2027-12-31）；经营所得个税年应纳税所得额 ≤200 万部分减半（2023–2027）。个体工商户可以做 ICP 备案与 App 备案，但**不能**取得 ICP 经营许可证（只发给公司）。
6. **真正的硬门槛不在支付而在「教育」属性**：《教育移动互联网应用程序备案管理办法》(2019) 的「提供者」列举的是教育行政部门、学校、企业和社会组织，前置条件含等保定级备案——两者事实上都排除自然人与个体户；且「双减」把英语列为学科类，面向义务教育阶段的线上学科类培训机构必须登记为**非营利法人**并取得办学许可证，2021 年教育部曾下线未取得许可的 K9 线上学科培训 App。一款面向小学 / 初中的付费英语单词 App 是否会被认定为「学科类培训」，是本项目最大的监管不确定性，必须作为前提问题处理。
7. **最便宜的合法组合**（详见末节）：个体工商户 + 个体户名义 ICP / App 备案 + 免费软著 + 微信支付 / 支付宝商户号（0.6 % 费率、无固定费）+ Apple 个人账号（¥688/年，12 % 佣金）+ 官网 APK / 小程序；年固定成本约 **¥1,000–2,500**（不含已有的服务器），而把现有服务器算进去约 ¥2,000–4,000。需要有限公司的触发点：教育 App 备案、等保、ICP 经营许可证、小米 / vivo / OPPO / 应用宝上架。

## 最便宜的合法路径（web + Android + iOS 都能收 ¥ 订阅）

前提：先解决 R3-29 的定性问题——把产品定位为「工具 / 自学辅助」而非「培训」，避免直播课、教师答疑、班级服务等培训机构特征；这不是支付问题，是能否做付费 K-12 英语的前提。

1. **登记个体工商户**（免费，约 3 天；经营范围写软件开发、信息技术服务、技术推广等，勿写教育培训）。
2. **以个体工商户为主体做 ICP 备案 + App 备案**（域名 ≈ ¥60–100/年，服务器已有；备案免费，5–10 个工作日，实际留一个月）。个人现有的备案若已是个人性质，建议主体变更为个体工商户，消除「个人备案不得经营」的灰色地带。
3. **免费登记软著**（60 日；加急属商业服务，¥数百–数千，未核实）。软著只在 Android 商店与小程序类目审核时需要，iOS 不需要。
4. **开微信支付普通商户号 + 支付宝商户**（营业执照 + 身份证 + 个人银行账户即可，0.6 % 费率，无年费）→ 用于 **web 订阅** 与 **官网直发 APK** 内的支付（Android 系统允许侧载；OPPO / vivo / 小米 / 荣耀 2026-11 起的侧载开发者验证会对未验证应用弹「未验证」提示，见 R3-13 来源）。
5. **iOS：Apple 个人账号 ¥688/年**，加入 Small Business Program，大陆佣金 12 %，订阅从首月起按 88 % 结算；用 StoreKit 自动续期订阅；绑定个人银行账户，接受 810 号令季度报送。
6. **可选：微信小程序**（主体个体工商户，认证 ¥300/年——企业 / 个体户认证费用未在本次核实）作为 Android 用户的第二收费入口；若暂不想办执照，则以个人主体 + 「工具」类目的虚拟支付起步（月 ≤¥10 万）。
7. **不要做的事**：用个人收款码 / 赞赏码收订阅费（R3-19）；在个人小程序上标「教育 / 学科培训」；在华为商店用非 IAP 支付（R3-11）。

**年固定成本估算**（不含已有服务器与 AI 模型费用）：Apple ¥688 + 域名 ≈ ¥80 + 小程序认证 ≈ ¥300（未核实）+ 记账 ¥0（季度 ≤30 万、自行申报）≈ **¥1,100/年**；若把一台轻量服务器（≈ ¥1,000–2,500/年）算入，约 **¥2,000–3,500/年**。变动成本：iOS 12 %，web / Android 0.6 %，个人小程序 Android 1 %。

**必须升级为有限公司的触发点**：(a) 教育部门或商店要求「教育 App 备案」（等保 + 企业主体，R3-27/28）；(b) 电管局认定付费服务为经营性互联网信息服务并要求 ICP 许可证（R3-10）；(c) 需要上小米 / vivo / OPPO / 应用宝（R3-12/13/14）；(d) 小程序要申请「教育」类目并带支付；(e) 收入规模超过小规模纳税人阈值且需要进项抵扣或引入合伙人。此时可用 R3-25 的「个体户变更为企业」保留信用代码与成立时间。
