# R1 — 可比中国单词 / 词典 / K-12 学习 App 的变现方式与价格（2025–2026）

检索日期：2026-11-11。来源以中国区 App Store 商品页（「App 内购买项目」清单，一手价格）、官网、公司财报 / 新闻稿为主，二手媒体仅用于历史与用户规模。价格均为人民币。

## 摘要（对一个人做的 K-12 背单词 App 意味着什么）

1. **市场已被训练成「免费可用 + 小额付费」**：所有可比 App（墨墨、不背、百词斩、扇贝、欧路、多邻国、有道）都是「免费下载 · App 内购买」，没有一家对核心背词功能收门票。付费点是「去限制」（墨墨单词上限）、「去广告 + 同步 + 发音库」（欧路、有道）、「会员特权」（扇贝、百词斩 PRO、不背大会员）。
2. **价格锚点非常集中**：月付 18–38 元，年付 98–268 元，终身 / 买断 108–538 元。学生端（大学生为主）年费集中在 98–168 元；家长付费的 K-12 产品（斑马、洪恩、小猿）年费集中在 168–268 元，另加 388–588 元的「永久包 / 系统课」。
3. **向家长卖比向孩子卖贵一个档**：洪恩英语（包年 268 / 永久 388–538 / 小学系统课年卡 398）、斑马（1 年会员 268）、小猿搜题（12 个月 168）都是家长付费；大学生向的墨墨 / 扇贝 / 不背一年只能收 98–163 元。这支持 word-dance 走「家长账户付费、孩子使用」的家庭模型。
4. **两个可直接借鉴的轻量模型**：墨墨的「单词上限」一次性买断（8–163 元，从 2017 年至今价格表未变，一个 10 人团队在 190 万注册用户时即已盈亏平衡），以及欧路的「买断 98–108 元 + 可选 AI 会员订阅」。两者都不依赖广告、不依赖投放，适合个人开发者。
5. **「打卡返学费」已死**：2019-05-13 微信安全中心封禁利诱分享朋友圈打卡，全行业取消朋友圈打卡机制；极光单词式「押金 / 学费 + 每日返现」模式靠未完成者的学费盈利，对 K-12 家长群体有口碑和合规风险，不建议。
6. **广告不是必选项**：墨墨、不背、欧路免费版都标注 / 宣称无广告，仍能盈利；带广告的是用户体量大的百词斩、扇贝、有道、多邻国、小猿。面向 4+ / 9+ 儿童的 App，无广告反而是卖点，也避开未成年人广告合规问题。
7. **支付渠道**：iOS 端全部走 Apple IAP（30 % 抽成，价格表因此呈 ¥8/¥12/¥18/¥28/¥98/¥168/¥268 等苹果价位阶梯）。安卓 / 网页端用微信 / 支付宝直收的证据只在扇贝（2015 年支付宝）和欧路官网（官网买断比 App Store 内购便宜 10 元）拿到一手；墨墨官网有「购买」入口但支付方式未核实。
8. **公开规模参考**：洪恩（iHuman）2025 年营收 8.07 亿、净利 0.95 亿、平均 MAU 2498 万、毛利率 67.9 %；网易有道 2025 年 AI 订阅销售额近 4 亿；百词斩母公司 2017 年营收 1.21 亿、净利 3356 万。头部数字对个人开发者只有「天花板」意义；更有参考价值的是墨墨 2017 年「10 人、190 万注册用户、盈亏平衡」这个样本。
9. **没有任何一家公布付费率**；本文所有「付费率」均未核实。

## 对 word-dance 的直接含义（综合判断，非事实）

- 可行的最小盈利形态是 **「免费核心 + 一次性买断（或年费）」**，价位 98–168 元 / 年或 108–298 元终身，向家长账户收费，不放广告。这与墨墨（10 人团队盈亏平衡）、欧路（买断 + 可选订阅）两个被验证过的小团队模型一致。
- 家长端可比价位（斑马 268 / 年、洪恩 268 / 年 + 398 系统课、小猿 168 / 年）说明 K-12 家长对 200–400 元 / 年有付费习惯，但这些产品都附带课程 / 真人 / 硬件内容；纯背词工具应锚在 98–168 元 / 年。
- 多子女家庭方案在国内可比 App 中几乎不存在（只有多邻国 6 人家庭版）——这是 word-dance 的监护人 + 子账号模型可以差异化的空白。
- 虚拟币 / 签到换会员（不背单词酷币、扇贝贝壳、斑马斑点）是提高留存的通用做法，但它们都需要运营投入；对一个人维护的产品，墨墨式「上限 + 复习即可免费提升」更省人力。
- 「打卡返现 / 押金」模式有 2019 年微信封禁先例，且面向未成年人有额外风险，不建议。
