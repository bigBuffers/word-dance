## Summary

1. **百炼 has no permanently free LLM.** The free tier is a one-time new-user grant: 1,000,000 tokens *per model* (input+output shared), valid 90 days, Beijing region only, 实名认证 required, non-renewable. For this app that is ≈167 content calls per model — about two days of traffic at 100 calls/day, or ~18% of the 912-call seed prewarm.
2. **After the free tokens, 百炼 pay-as-you-go is nearly free at this workload:** `qwen3.7-flash` (strict JSON-Schema support, 1M context, 131K max output, 30,000 RPM) costs ≈¥0.0036 per content call → ≈¥15/month for *all four jobs* at 100 content calls/day; the whole 912-call seed is ≈¥3.3. `qwen3.8-flash` (SuperCLUE 66.4) is ≈¥54/month.
3. **百炼 exposes an Anthropic-format Messages endpoint usable with ordinary pay-as-you-go keys** (`https://dashscope.aliyuncs.com/apps/anthropic`, recommended `https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/apps/anthropic`; also Singapore/Tokyo/US/EU hosts). It supports `tools`/`tool_choice`/`thinking` and a platform extension `output_config.format={type:"json_schema"}` with strict mode on qwen3.7/3.8/GLM/most DeepSeek models — the same body field Claude Code ≥2.1.287 uses for `--json-schema`. No Coding Plan needed; Coding Plan / Token Plan are explicitly **forbidden for backends** and **authorise training on your data**, so pay-as-you-go is the only compliant 百炼 route.
4. **Overseas server:** region keys are not interchangeable, but the Beijing endpoint answered an unauthenticated probe from a US egress with HTTP 401 (reachable, not geo-blocked); no document forbids calling it from a Tokyo IP. A Tokyo region exists (`{WorkspaceId}.ap-northeast-1.maas.aliyuncs.com`) with Beijing-level prices under “全球” deployment but no free quota.
5. **ModelScope API-Inference is the only genuinely free, permanent option on the Alibaba side** (2,000 calls/day/account, per-model caps ≤500/day, single concurrency, reset 00:00 UTC+8), and today it serves strong open weights (DeepSeek-V4.1-Flash, GLM-5.2, Qwen3.5-397B-A17B, Qwen3.8-27B, MiniMax-M3) plus a Beta Anthropic-compatible `/v1/messages`. But it is officially “非商业化、非盈利”, not for SLA/online use, requires binding an Alibaba Cloud account with 实名, cuts quotas without notice, and its model list churns (Kimi-K2, Qwen3-235B, Qwen3-Coder-480B are gone).
6. **Quality:** ModelScope's best free models are top-30 on the LMArena Chinese-language board (DeepSeek-V4.1-Flash 1523, GLM-5.2 1525 vs Claude Sonnet 5.5 1545, Claude Fable 5.1 1565) and SuperCLUE #2 (DeepSeek-V4.1-Flash 71.8) — clearly above Zhipu's permanently-free GLM-4.7-Flash (30B-A3B; its larger sibling GLM-4.7 scores 1495). Zhipu wins on being a commercial-grade, permanently free API with no 实名 hurdle beyond its own; ModelScope wins on raw model quality but is a best-effort, non-commercial sandbox.
7. **Recommendation in one line:** fallback #1 = 百炼 pay-as-you-go `qwen3.7-flash` (thinking off, strict schema) via the Anthropic-format endpoint through the existing Claude CLI path or via a 60-line OpenAI-compatible adapter; ModelScope only as a tier-3 free best-effort backend for low-volume lookups/SVG; never Token Plan/Coding Plan.
