# Fallback providers for word-Dance — Volcengine Ark (Doubao), DeepSeek, Moonshot Kimi, MiniMax

Slice key: `bytedance-deepseek` · research date 2026-11-04 · all URLs accessed 2026-11-04 unless stated · sources marked **[zh]** are Chinese-language.

## Summary

1. None of the four vendors has a *permanent* free tier usable for this app in Nov 2026. Ark gives a one-time ≈500k tokens per model; its daily "协作奖励计划" rebate lost the useful LLMs on 2026-10-08; DeepSeek gives nothing; Kimi's ¥15 voucher is explicitly not valid on K3/K3.1 Pro; MiniMax only has an activity-dependent voucher.
2. At this workload the cheap models are "almost free" anyway: Doubao-Seed-2.0-mini ≈ ¥25/month, Doubao-Seed-2.1-lite ≈ ¥37, DeepSeek-flash ≈ ¥54 (off-peak) – ¥108 (peak), MiniMax-M3.1-Flash ≈ ¥54 nominal (but thinking cannot be switched off); the 912-call prewarm costs ¥8–33 one-time on those. Kimi K3.1 Pro (≈ ¥894/month) is the outlier.
3. Model names in the task brief are stale: DeepSeek retired `deepseek-chat`/`deepseek-reasoner` on 2026-07-24 (now `deepseek-flash` = V4.1-Flash-1017, `deepseek-v4-pro`); Kimi closed the K2 series to new users on 2026-10-31 (K3.1 Pro is the current model); MiniMax's Anthropic endpoint only serves `MiniMax-M3.1-Flash` / `MiniMax-M3`; Ark is on Doubao-Seed-2.x.
4. Structured output: Ark (Chat `response_format: json_schema` + `strict`, and `output_format` on its Messages API) and Kimi (`json_schema`+`strict`, Messages `output_config.format`) support schema-enforced JSON natively; DeepSeek's OpenAI path has only `json_object` (plus `strict` tool calls); MiniMax's current models document no JSON mode at all on the mainland OpenAI-compatible API.
5. All four expose an Anthropic-format Messages endpoint that accepts client `tools`; because Claude Code implements `--json-schema` as a synthetic `StructuredOutput` tool call, the *unmodified* `claude` CLI can in principle be pointed at any of them via `ANTHROPIC_BASE_URL` + `--model <provider model>` — but `--max-budget-usd`/`total_cost_usd` become meaningless and `--fallback-model` cannot cross providers.
6. Access from Tokyo/Singapore: DeepSeek is a single global platform (PayPal/cards accepted) — safest; Kimi CN has no documented geo block; MiniMax keys are region-bound (CN vs intl platforms); Ark's platform terms grant use "仅在中国大陆地区" and ByteDance's overseas sibling is BytePlus ModelArk (USD, separate account).
7. Recommended order for an automatic fallback: DeepSeek-flash (primary fallback, Tokyo-friendly, strong Chinese, 1M context) → Doubao-Seed-2.1-lite on Ark (cheapest schema-enforced JSON, mainland-only terms) → MiniMax-M3.1-Flash; Kimi K3.1 Pro only as a quality fallback for `consolidate_bank`.
8. DeepSeek itself had its "19th major outage of 2026" on 2026-11-03, so the fallback chain should have two providers, not one.

### F3 — DeepSeek has no free tier or sign-up credit in 2026; prepaid balance, global payments, concurrency-only limits
- **Claim.** No free quota or new-user credit exists; top-up requires 实名; balance never expires and is refundable; limits are per-account concurrency (2500 flash / 500 pro) with 429 on excess; no RPM/TPM.
- **Evidence.** Pricing pages (above) contain no free-quota clause; rate-limit page https://api-docs.deepseek.com/quick_start/rate_limit — "deepseek-flash: 2500 concurrent connections", "deepseek-v4-pro: 500", "When the concurrency limit is exceeded, you will receive an HTTP 429 error code", "If the request has not started inference after 10 minutes, the server will close the connection", non-streaming keep-alive "Continuously return empty lines". - **Implication.** DeepSeek is pay-as-you-go from the first token, but at ≈¥54–108/month it is the cheapest *globally reachable* option; the keep-alive blank lines mean an OpenAI-compatible client must tolerate leading whitespace.
- **Confidence.** high for pricing/limits; medium for "no bonus" (official FAQ is a JS app not fetchable here).

### F4 — DeepSeek structured output: `json_object` only on the OpenAI path, `strict` tool calls, Anthropic endpoint ignores `format`
- **Claim.** `response_format: {type: "json_object"}` requires the word "json" plus an example in the prompt and may return an all-blank `content`; there is no `json_schema` response_format; `tools[].strict=true` guarantees schema-valid tool arguments. The Anthropic endpoint `https://api.deepseek.com/anthropic` supports system/tools/tool_choice/thinking/stop/temperature, maps `claude-opus*`→`deepseek-v4-pro` and other `claude*`→`deepseek-flash`, and ignores output-format settings.
- **Evidence.** https://api-docs.deepseek.com/guides/json_mode — "Include the word 'json' in the system or user prompt, and provide an example of the desired JSON format"; "If the model's output cannot be recognized as JSON, the API replaces the non-JSON content with spaces … the returned `content` may contain only spaces". Chat reference — response_format "Supports `text` or `json_object`"; tools strict: "If set to true, the API will use strict-mode for the tool calls to ensure the output always complies with the function's JSON schema". Anthropic guide https://api-docs.deepseek.com/guides/anthropic_api — "Authenticate with either `x-api-key: <API_KEY>` or `Authorization: Bearer <API_KEY>`", unsupported: `top_k`, `mcp_servers`; **[zh]** Messages reference https://api-docs.deepseek.com/zh-cn/api/create-message.md — "`format` 等输出格式设置会被忽略", "兼容字段 `container`、`mcp_servers`、`service_tier` 和 `top_k` 会被忽略".
- **Implication.** On DeepSeek the robust way to get `content_v1.json` is either (a) the OpenAI path with a single strict tool whose `parameters` = the content schema and `tool_choice` forcing it, or (b) the Anthropic path + the CLI's `StructuredOutput` tool (F21); plain `json_object` needs the schema pasted into the prompt and an empty-content guard.
- **Confidence.** high.

Payment methods incl. PayPal/cards (F3) show overseas accounts are expected.
- **Implication.** Acceptable for word-definition prompts (no user PII is sent — prompts are words only), but record it in the privacy page; nothing blocks the Tokyo VPS.
- **Confidence.** medium (second-hand quotes).

- **Evidence.** **[zh]** https://docs.volcengine.com/docs/82379/1958523 (结构化输出) — json_schema block with `"strict": true`; "250615及之后版本的大语言模型"; example `doubao-seed-2-1-pro-260915`; structured output unavailable with TPM 保障包. ### F21 — How the `claude` CLI behaves against a third-party base URL (facts that constrain the failover design)
- **Claim.** (a) `--json-schema` is implemented as a synthetic tool named `StructuredOutput` that the model must call; the SDK validates and re-prompts, failing with subtype `error_max_structured_output_retries`, and a `success` result may still lack `structured_output`. (c) `--fallback-model` triggers only on overloaded/unavailable (never auth, billing, rate-limit, transport) and targets Claude models. ## Recommendations

1. **Ranking for this app's four jobs (all require JSON + zh/en quality):**
   - **#1 DeepSeek `deepseek-flash`** — ¥54–108/month, reachable from Tokyo with card/PayPal, 1M context, thinking switchable off, strong Chinese; JSON via forced strict tool or `StructuredOutput`. Weakness: outage record (F19).
   - **#2 Volcengine Ark `doubao-seed-2-1-lite`** — ¥37/month, native `json_schema strict`, Messages API with thinking toggle, 500k free tokens to validate prompts; weakness: terms say mainland-only use (F10) — use **BytePlus Seed 2.0 Mini/2.1 Turbo** instead if the server stays overseas.
   - **#3 MiniMax `MiniMax-M3`** (not M3.1-Flash for cost predictability) — ¥113/month; forced-tool JSON only; pick CN or intl platform to match the server region.
   - **#4 Kimi `kimi-k3.1-pro`** — best quality/instruction following but ≈¥900/month and thinking always on; use only for `consolidate_bank` or as an operator-selected override.
2. **Failover policy (owner's rule "当 Claude 不成功，直接用备选方案"):** on a Claude result in {`auth`, `spawn_error`, `timeout`, `overloaded`, `error`} re-run the *same* job group immediately on the fallback provider (do not wait for the 6-strike overload pause); store `kv ai.claude_down_until = now+30min` so later jobs skip Claude; let `probe.py` re-check Claude every 10 min and clear the flag. Keep the existing pause only for the case where the fallback also fails.
3. **Option A — wrapper-only failover (effort ≈ 0.5 day, no Python change):** point `WD_CLAUDE_BIN` at a script that runs the real `claude`, inspects exit code/JSON, and on failure re-execs `claude` with `ANTHROPIC_BASE_URL=https://api.deepseek.com/anthropic`, `ANTHROPIC_AUTH_TOKEN=<DeepSeek key>`, `--model deepseek-flash` (argv rewrite) and `--fallback-model` removed. The CLI gives no flag to send `thinking: disabled` to a third-party endpoint, so DeepSeek's default thinking (effort high) is billed as output on this path — try exporting `MAX_THINKING_TOKENS=0` in the wrapper and verify in `modelUsage`, otherwise accept the extra output cost or use option B. Prefix error text with `fallback:` so `AUTH_RE` hits on the fallback do not pause the whole app. Second leg: Ark with `ANTHROPIC_BASE_URL=https://ark.cn-beijing.volces.com/api/compatible` (the CLI appends `/v1/messages`) and `--model doubao-seed-2-1-lite-260915` — unverified, see Q1/Q2. Accept `cost_usd=0` in the ledger for fallback calls and add a CNY counter in the wrapper's log.
4. **Option B — provider transport in `runner.py` (effort ≈ 1.5–2 days incl. tests):** add `WD_AI_FALLBACK_PROVIDER={deepseek|ark|minimax|kimi}`, `WD_AI_FALLBACK_BASE_URL`, `WD_AI_FALLBACK_MODEL_NAME`, `WD_AI_FALLBACK_API_KEY`; implement an OpenAI-compatible `chat/completions` transport that returns the same `Parsed` envelope (Ark/Kimi: `response_format json_schema strict`; DeepSeek: single strict tool forced via `tool_choice`, `thinking: {type: disabled}`; MiniMax: forced tool); migration `0010` adding `provider TEXT` and `cost_cny REAL` to `ai_calls`; convert CNY→USD at a fixed `WD_CNY_PER_USD` so the existing USD caps keep working; set per-provider `max_tokens` ≥ 16k (Doubao default 4k). This also removes the CLI's "no compatibility guarantee" risk for the fallback path.
5. **Provider-side hygiene (effort ≈ hours):** DeepSeek — run prewarm in Beijing off-peak (half price; nightly worker already exists); Kimi — recharge ¥50 once to leave Tier0 if ever used; Ark — authorise only the models you will call (each one's free 500k is separate) and leave the 协作奖励计划 unjoined (permanent training licence); MiniMax — never send `temperature` expectations (ignored on the Anthropic path).
6. **Privacy/terms text (effort ≈ 1 hour):** add a line that fallback providers (DeepSeek/Moonshot) may use prompts for model improvement; prompts contain only vocabulary words and bank rows, never account data — keep it that way in `consolidate_bank`.
7. **Validation before go-live (effort ≈ 2–3 hours, needs real keys, ¥10–20):** run 20 content calls per candidate through `validate_item` and record pass rate + output tokens; this settles the verbosity multiplier (F20) and the JSON reliability gap no leaderboard covers.
