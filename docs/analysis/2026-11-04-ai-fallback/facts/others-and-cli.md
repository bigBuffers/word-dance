# Fallback research — slice `others-and-cli`: remaining free domestic options, Claude Code as a gateway client, quality evidence

Date of research: 2026-11-04 (all URLs accessed that day unless noted). Repo: /Users/sqin/word-dance @ 9ab13a5. Sources marked **[zh]** are Chinese-language. Anything older than six months is flagged **[old]**.

## Summary

1. Three of the four "historic" free Chinese tiers this slice was asked to evaluate no longer exist in a usable form: Baidu retired ERNIE-Speed-8K/128K, ERNIE-Lite-8K and ERNIE-Tiny-8K on 2026-06-09 (Speed-Pro/Lite-Pro on 2026-06-30, the whole ERNIE 3.5/4.0 line on 2026-10-29, v1 API on 2026-08-31, gift quotas on 2025-11-03); Tencent retired hunyuan-lite with 45 other models on 2026-06-22 and is closing the legacy platform (2026-09-30; ChatCompletions API scheduled 2026-12-21) in favour of the paid multi-vendor TokenHub; iFlytek Spark Lite is still free but is an 8K-in/4K-out model with QPS≈2, no function calling and no leaderboard evidence, which makes it unfit for the content and consolidate jobs.
2. The only genuinely free, Anthropic-format-reachable candidates that remain are Zhipu GLM-4.7-Flash (免费/免费 on the official price list, 200K context, 128K output, function calling + JSON output; `https://open.bigmodel.cn/api/anthropic`) and SiliconFlow's permanently free ≤9B models (Qwen3-8B etc.) — and, contrary to the task premise, SiliconFlow DOES expose an Anthropic Messages endpoint at `https://api.siliconflow.cn/v1/messages` (probed today: 401 "Token is invalid."; the `/anthropic/v1/messages` path is the one that 404s). ModelScope's free API (2,000 calls/day) is OpenAI-format only.
3. Claude Code's `--json-schema` is implemented as a `StructuredOutput` **tool call** (plus, on recent versions, an `output_config.format` beta field). A fallback model therefore has to do Anthropic-format tool use reliably against the nested 10-item `content_v1.json` schema; the beta field must be switched off for most third-party upstreams (`CLAUDE_CODE_DISABLE_STRUCTURED_OUTPUTS=1`, v2.1.288+, or `CLAUDE_CODE_DISABLE_EXPERIMENTAL_BETAS=1`), and 2026 GitHub issues show exactly these failure modes (missing `thinking` on structured-output requests → 400 at Moonshot; plain text instead of `tool_use` from 8B models; silent exit-0 with no request on some third-party key formats).
4. `--fallback-model` cannot implement the owner's failover: it only switches among models served by the *same* base URL and only on overloaded/unavailable errors, never on auth or rate-limit errors. Provider failover has to be done by the app: choose the provider before spawning, set `ANTHROPIC_BASE_URL`/`ANTHROPIC_AUTH_TOKEN`/`ANTHROPIC_MODEL` (+ the three `ANTHROPIC_DEFAULT_*_MODEL` slots) in the `WD_CLAUDE_BIN` wrapper, and retry the same job immediately.
5. `total_cost_usd` is a client-side estimate from a bundled price table; for an unknown model id the `costBasis` is `unknown`, so the app's per-call/daily USD caps become meaningless on a fallback unless a Managed-scope `modelPricing` table is deployed or the app prices tokens itself (the ledger already stores tokens and `model_used`).
6. Quality evidence (LMArena zh 2026-10-27, SuperCLUE 2026-10-22, IFEval/BFCL reports): the ≥30B "Flash" MoE models (GLM-5.3-Flash #20 on LMArena zh / 68.10 SuperCLUE; DeepSeek-V4.1-Flash #30 / 71.81; Qwen3.8-Flash 66.41) are a different class from the 7–9B free models (Qwen3-8B IFEval 83–85, BFCL v3 60–68). No public IFEval/BFCL/LMArena evidence exists for ERNIE-Speed, Spark Lite or hunyuan-lite. Structured-output studies from 2025–2026 agree that schema validity is the easy part and semantic accuracy the hard part, so `content.validate_item` must stay strict.
7. Cheapest paid siblings at this app's shape (≈2k in + ≈4k out per content call): Spark Ultra ≈¥0.005/call, Hunyuan-a13b ≈¥0.009 (legacy, retiring), GLM-5.3-Flash ≈¥0.013, GLM-4.7-FlashX ≈¥0.013, DeepSeek-flash ≈¥0.018 off-peak / ≈¥0.036 peak; the one-time 912-call prewarm costs ¥4–¥35 on any of them.

### Part 2 — Claude Code as a gateway client (technical only)

**F8. The gateway mechanics: one base URL per process, bearer vs x-api-key, alias slots, and what the CLI assumes about unknown model ids.**
- Claim: `ANTHROPIC_BASE_URL` selects the Anthropic Messages format (`/v1/messages?beta=true`, optional `/v1/messages/count_tokens`); `ANTHROPIC_AUTH_TOKEN` → `Authorization: Bearer`, `ANTHROPIC_API_KEY` → `x-api-key` (always used in `-p` mode); `--model` accepts any full model name and is not validated up front; the `sonnet/opus/haiku` aliases resolve to Anthropic ids unless `ANTHROPIC_DEFAULT_*_MODEL` redirects them; for an unrecognized id the CLI assumes a 200K window, a 32,000 default/128,000 max output, and sends every current-Claude request field (adaptive `thinking`, effort, `context_management`, `output_config`), which third-party upstreams can reject with 400s unless the beta switches are set.
- Evidence: https://code.claude.com/docs/en/llm-gateway — "Any gateway that exposes a supported API format works. ## Recommendations

R1 (S, config/decision). Fallback shortlist, in order: **GLM-4.7-Flash** via `https://open.bigmodel.cn/api/anthropic` as the free default; **SiliconFlow `https://api.siliconflow.cn`** (Anthropic path `/v1/messages`) with `Qwen/Qwen3-8B` as the zero-cost emergency tier and `deepseek-ai/DeepSeek-V4-Flash` or `glm-5.3-flash` as the paid step-up on the same key; **DeepSeek `deepseek-flash`** direct as the quality/paid tier (prefer off-peak). Drop Baidu ERNIE-Speed/Lite, Tencent hunyuan-lite (both retired) and Spark Lite (8K/4K, no tool calling) from the automatic path.

R2 (M, 1–2 days). Build the `WD_CLAUDE_BIN` wrapper as the single place where the provider is chosen: read `ai.provider` (file or env written by the backend), then export `ANTHROPIC_BASE_URL`, `ANTHROPIC_AUTH_TOKEN` (not `ANTHROPIC_API_KEY`), `ANTHROPIC_DEFAULT_SONNET_MODEL=ANTHROPIC_DEFAULT_OPUS_MODEL=ANTHROPIC_DEFAULT_HAIKU_MODEL=<provider model id>` (so the runner's `--model sonnet` resolves without code changes), `CLAUDE_CODE_MAX_CONTEXT_TOKENS`/`CLAUDE_CODE_MAX_OUTPUT_TOKENS` per model, `MAX_THINKING_TOKENS=0` (or a budget for providers that require thinking), `CLAUDE_CODE_DISABLE_STRUCTURED_OUTPUTS=1` (fallback to `CLAUDE_CODE_DISABLE_EXPERIMENTAL_BETAS=1` if 400s persist), `API_TIMEOUT_MS≥600000`, and the F12 traffic switches; strip `--fallback-model` if present; pin the CLI version (several behaviours are gated at 2.1.287/288/304/314).

R3 (M–L, 2–4 days). Failover in `wd.ai`: on `auth`, `spawn_error`, the 6-in-a-row `overloaded` streak, or N consecutive `timeout`s from the Claude path, set `ai.provider=<fallback>` with a TTL, re-run the *same* job immediately (owner requirement), and probe Claude periodically to switch back. Add `provider` to `ai_calls` (or derive it from `model_used`), force `WD_AI_CONCURRENCY=1` on free providers, keep `WD_AI_HOURLY_CALL_CAP`, and price tokens in the app from a per-provider CNY table (store converted USD in `cost_usd`) because `total_cost_usd` is unreliable for unknown ids (F11). Mark fallback-generated rows for later regeneration (CLAUDE_INTEGRATION.md:411 already anticipates this via `model_used`).

R4 (S–M, half a day with provider keys). Before enabling: run the real tier-0 argv (`--tools "" --json-schema content_v1.json …`) against each candidate 20–30 times with the real prompts; measure `structured_output` presence, `validate_item` pass rate, latency and `max_tokens` behaviour; capture the raw error bodies for 401/429/5xx and extend `AUTH_RE`/`OVERLOADED_RE` (runner.py:71-73) with the vendor strings; run the same from the Tokyo VPS to confirm reachability of `open.bigmodel.cn`, `api.siliconflow.cn`, `api.deepseek.com`.

R5 (S). Account/terms hygiene: complete personal 实名 on Zhipu and SiliconFlow (mandatory there since 2026-05-15); set SiliconFlow's IP whitelist to the VPS; note that iFlytek's terms allow de-identified reuse of prompts for product optimisation (opt-out by request), while SiliconFlow and Tencent commit to no training; keep the 10-friend workload well under free-tier limits (Zhipu concurrency, SiliconFlow fixed RPM/TPM).

R6 (S). Job routing on fallback: route `consolidate_bank` only to ≥128K-context models (GLM-4.7-Flash 200K, DeepSeek-flash 1M); send `generate_content`/`lookup_word`/`generate_svg` to the small free model only with `WD_AI_BATCH_SIZE` lowered (e.g. 5) and the existing `invalid_output` retry; never route the one-time 912-call prewarm to a free tier with daily caps (ModelScope 2,000/day; Zhipu single-concurrency) without spreading it over days.
