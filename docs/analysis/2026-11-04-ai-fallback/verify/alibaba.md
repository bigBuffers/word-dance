## Omissions / new findings (for the fallback decision)

1. **Thinking cannot be assumed off, and the CLI route makes it hard to turn off.** 百炼 lists `qwen3.7-flash` as "混合思考模式，默认开启思考模式" and bills thinking as output tokens (deep-thinking page). Claude Code sends adaptive `thinking` to unrecognised model IDs on the Anthropic format and, on a 400, retries with the other type and *keeps* the field; `CLAUDE_CODE_DISABLE_THINKING=1` merely omits the field ("the model may still think"). Either send `thinking:{"type":"disabled"}` from an adapter, or test `CLAUDE_CODE_EXTRA_BODY='{"thinking":{"type":"disabled"}}'` and confirm `usage.output_tokens ≈ visible JSON` before trusting F11's ¥15/month. (Sources: help.aliyun.com/zh/model-studio/deep-thinking; code.claude.com/docs/en/llm-gateway-protocol; code.claude.com/docs/en/env-vars, all 2026-11-04.)
2. **Use the workspace host, not `dashscope.aliyuncs.com`.** regions page: "DashScope 域名（dashscope.aliyuncs.com）自2026年9月30日起不再支持新特性"; the 业务空间专属域名 has a 3600 s request timeout (legacy 600 s) and is what the Claude Code setup page uses for 按量计费. The digest's R2 and R5(a) point at the frozen host.
3. **`output_config` is a 400 on deepseek-v4.1-flash / -1017 and `thinking.budget_tokens` is being deprecated** (anthropic-api-messages page). So "DeepSeek-V4.1-Flash on 百炼 via the Anthropic path with structured output" is not an option, and any adapter should use `output_config.effort`, not `budget_tokens`.
4. **Billing failure modes:** 用完即停 is off by default, so the free grant silently rolls into pay-as-you-go ("免费额度用完后自动转为按量付费"); overage can create 欠费 and "欠费限制按商品 Code 隔离"; 欠费 surfaces as HTTP 403 `code: Arrearage` "Access denied, please make sure your account is in good standing."; 延期免停 is **off by default for new accounts**, so a balance < 0 means immediate 欠费停服 (help.aliyun.com/zh/user-center/exemption-of-suspension-after-delinquency); account balance must be ≥ 0 to open; recharge is 支付宝/银联/网银. Map `Arrearage` and `AllocationQuota.FreeTierOnly` to `budget` and add a balance alert. Also check whether the owner's 百炼 was opened before — pre-2025-09-08 accounts "免费额度有效期可能不足90天".
5. **SuperCLUE numbers are third-party compilations, not an official edition** (llmlearner/datalearner "Powered by DataLearner", last official report 2026年7月 without DeepSeek-V4.1-Flash / Qwen3.8-Max-0902; cross-edition scores "not directly comparable"). Drop them from the decision or label them accordingly; rely on LMArena Chinese + the planned 50-word `validate_item` run.
6. **ModelScope operational details:** today's per-model ceiling is ≈200 calls/day (not 500), the API returns `modelscope-ratelimit-requests-remaining` / `modelscope-ratelimit-model-requests-remaining` headers (read them instead of guessing), unbound accounts get `401 please bind your alibaba cloud account before use`, the Anthropic-mode error body is non-Anthropic (`{"detail":"Error code: 401 - {...}"}`, 403 when no key), and `/v1/messages/count_tokens` answers 200 even unauthenticated. Also 百炼-side: dated snapshot IDs carry 60–120 RPM (e.g. `qwen-plus-2025-12-01` 120 RPM / 1M TPM) versus 30,000 RPM for the alias, and `deepseek-v4.1-flash` is capped at 120万 TPM at every spend tier.
