# iOS distribution for <= 10 friends in mainland China (Nov 2026): TestFlight, Ad Hoc, home-screen web app, Xcode

Slice key: `ios` · research date 2026-11-04 · repo baseline `main` @ 9ab13a5 · owner Mac: macOS 26.7.1, Apple Silicon, no Xcode.
All web facts below were fetched on 2026-11-04 unless marked "(reused from 2026-11-03 slice, not re-fetched)". Where this network blocked a source (gs.statcounter.com refused both via curl and via the fetch tool, HTTP CONNECT 403) the figures are relayed through the search tool and marked medium confidence.

## Summary

1. Nothing Apple-side blocks a mainland individual: the Apple Developer Program costs ¥688/yr (99 USD) via the Apple Developer app with 身份证 + selfie (CFCA verification), the legal name becomes the public seller name, Apple promises confirmation "within 24 hours" of purchase and community data says 1–3 days with multi-week outliers only when name/address data mismatch. The Apple Developer app v11.1.1 needs iOS 26.0 / macOS 26.0 — the owner's Mac qualifies, so enrollment does not depend on an iOS 26 iPhone.
2. The review-free binary path is TestFlight **internal** testing: up to 100 App Store Connect users per group (individual accounts may add 50 users), roles Account Holder/Admin/App Manager/Developer/Marketing, no Beta App Review, builds live 90 days. External testing (public link, 10,000) sends the first build of every version through Beta App Review, which applies the App Review Guidelines (Guideline 2.2 says so explicitly), with a cap of six builds per 24 h.
3. The TestFlight app (4.4.1, iOS 16+) is on the China mainland App Store; Apple staff state "TestFlight does not have territory restrictions"; Apple's ICP wording is tied to the App Store product page / China availability and never mentions TestFlight; the mainland "TF签名" industry relies on exactly this. Residual risk: since 2025-01 Apple's TestFlight fine print allows IP-based blocking of betas "subject to legal restrictions in some regions" (used for TikTok in the US).
4. Ad Hoc (100 devices per type per year, UDID registration, Configurator/Device Hub/OTA manifest, ~1-year profiles) is a workable fallback; the free Personal Team (3 devices, 3 apps/device, 7-day profiles, no TestFlight/Ad Hoc/push) is not usable for friends.
5. Toolchain: Xcode 27.2 (released 2026-10-30, 3.12 GB download, macOS 26.6+, iOS 27.2 SDK, on-device debugging iOS 17+) is the current build; since 2026-04-28 every upload to App Store Connect — TestFlight included, because the rule is worded "uploaded to App Store Connect" — must use the iOS 26 SDK, and from April 2027 the iOS 27 SDK; Capacitor 8 needs Xcode 26+, Node 22+, iOS 15+.
6. The zero-cost path already works: on iOS 26 "every website added to the Home Screen opens as a web app" with "zero requirements for installability"; Web Push + badging exist since 16.4 for home-screen web apps only, without a developer account; home-screen apps have their own cookie/storage jar (cookies are copied at install since 17.2, so a cookie session survives), are exempt from ITP's 7-day purge, and can be added from Safari, Chrome, Edge and SFSafariViewController but **not** from WeChat's in-app browser, which needs a "在Safari中打开" handoff.
7. Guideline 4.2 ("elevate it beyond a repackaged website") is enforced against hybrid/Capacitor shells in App Store review (Nov 2025 and Jan 2026 forum cases, Apple staff: "to the reviewer the app is a browser around someone else's site"); Beta App Review has rejected on design grounds too, so an external TestFlight link is the wrong channel for a remote-shell app, while internal TestFlight has no review at all.
8. China iOS version mix (StatCounter, relayed): iOS 26.x ≈ 75 % of iOS web traffic in Aug 2026, iOS 18.x ≈ 16 %; Apple reports 86 % of recent iPhones on iOS 26. A deployment target of iOS 17 covers essentially everyone; TestFlight itself needs iOS 16.
9. Recommended for <= 10 friends: (a) now — home-screen web app from Safari (add manifest/icons + WeChat handoff page, optional Web Push); (b) if a real app is wanted — enroll, install Xcode 27.2, Capacitor 8 shell, upload as "TestFlight Internal Only", add the friends as ASC users with the Marketing role and access limited to this app, re-upload every <= 90 days; (c) Ad Hoc only for a friend who refuses an ASC invitation; never external TestFlight or the App Store for this circle.

## Findings

### F1 — Apple Developer Program price from mainland China: ¥688/yr (99 USD), paid with an Apple Account payment method but never with Apple Account balance
- Claim: The individual membership is 99 USD/yr; enrolled through the Apple Developer app in mainland China it is an auto-renewing ¥688/yr; the fee cannot be paid from Apple Account balance; a mainland Apple Account can carry Alipay, WeChat Pay, Douyin Pay or most credit/debit cards.
- Evidence: "Apple Developer Program Enrollment – Support", https://developer.apple.com/support/enrollment/ (accessed 2026-11-04): "The Apple Developer Program annual fee is 99 USD"; "the Apple Developer Enterprise Program annual fee is 299 USD, in local currency where available." · "在 Apple Developer App 中注册", https://developer.apple.com/cn/help/account/membership/enrolling-in-the-app/ (accessed 2026-11-04): "以每年 ¥688 续订"; "Apple Developer Program 会员费用不接受 Apple 账户余额 (通过兑换 Apple Gift Card 或直接充值) 付款方式。" · "Payment methods that you can use with your Apple Account", https://support.apple.com/en-us/HT202631 (published 2026-08-07, accessed 2026-11-04), China mainland row: "Alipay, Apple Account balance (from App Store top-up card or adding funds), Douyin Pay, Most credit and debit cards, WeChat Pay". Fapiao: enrollment page: "If you completed your purchase on the Apple Store Online in China mainland and would like to request a fapiao, call 400-666-8800".
- Implication: Budget ¥688 recurring; bind Alipay/WeChat Pay/UnionPay card to the Apple Account before enrolling; do not top up balance for this.
- Confidence: high.

## Recommendations (effort for one experienced developer)

1. **Ship the web app to the friends' Home Screens now (0.5–1 day).** Add `manifest.webmanifest` (name, short_name, id, start_url `/today`, scope `/`, display standalone, theme_color) and 180/192/512 px PNG + SVG icons in `frontend/public`, link them from `frontend/index.html`, keep the existing `apple-mobile-web-app-*` metas; no CSP change (F14, F15, F18). 2–3 h.
2. **WeChat handoff screen (0.5 day).** Detect `MicroMessenger` in the UA on the landing/login route and show a full-screen "右上角 ··· → 在Safari中打开" guide with a copy-URL button; also show an "添加到主屏幕" hint when `display-mode` is `browser` on iOS Safari (F16). 3–4 h.
3. **Optional Web Push reminders (3–5 days, backend-heavy).** `push_subscriptions` table + VAPID keys + `send_webpush` job + service worker + a settings toggle inside a user gesture; verify the public host can reach `*.push.apple.com` (F15; sizing reused from the 2026-11-03 delivery slice). Decide after the friends have used the Home Screen app for a week.
4. **If a real iOS app is wanted: review-free internal TestFlight (≈ 1.5–2 weeks elapsed, ≈ 5–7 person-days).**
   - Day 0: enroll via the Apple Developer app on the Mac, legal name exactly as on the 身份证, pay ¥688 with Alipay/WeChat Pay/card (F1–F3). 1 h + 1–3 days waiting.
   - Day 0–1: install Xcode 27.2 from the Mac App Store (3.12 GB + iOS 27 simulator runtime) over the proxy; verify with `xcodebuild -version` (F11). 0.5 day mostly waiting.
   - Day 1–5: Capacitor 8 project with the bundled Vite build, `CapacitorHttp` + absolute API base and signed/tokenised `/media` URLs or a bearer-token path (backend changes documented in the 2026-11-03 slice); deployment target iOS 17 (F13, F21). 3–5 days to a working build.
   - Day 5–6: Archive → Distribute → "TestFlight Internal Only"; create an internal group; add each friend as an ASC user with the Marketing role and access limited to word-Dance; they accept within 3 days and install TestFlight (F4, F22). 1–2 h plus friend latency.
   - Ongoing: calendar entry to re-upload every ≤ 80 days (F6); re-archive with the current Xcode before each April (F12). ≈ 1 h per cycle.
5. **Do not use external TestFlight or the App Store for this circle** unless the build has the 4.2 differentiation work (offline today-batch, APNs, haptics, native share) from the earlier slice (3–5 weeks); a remote-URL shell has a real chance of a 4.2 bounce in Beta App Review (F19, F20).
6. **Ad Hoc only as an exception (0.5 day setup + 10 min per friend):** collect UDIDs, register them, export an Ad Hoc .ipa with the OTA manifest, host both on the HTTPS domain, send the `itms-services://` link; renew yearly (F9).
7. **Ask the friends two questions before anything else:** iOS version (≥ 16 for TestFlight, ≥ 16.4 for push, ≥ 17.2 for cookie copy) and whether they are willing to accept an App Store Connect invitation (F4, F21).
